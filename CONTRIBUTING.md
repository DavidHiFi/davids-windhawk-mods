# Contributing to Windhawk Taskbar Styler

Thanks for helping. Bug reports, ideas and pull requests are all welcome.

## Reporting a bug

[Open an issue](https://github.com/DavidHiFi/davids-windhawk-mods/issues/new) and include:

- what you did, what you expected and what happened instead
- your Windows version and the Windhawk version
- the log file or a screenshot showing the issue

## Sending a pull request

1. Fork the repo and create a branch from `master`.
2. Follow the installation steps in README.md.
3. Keep each pull request to one change, and describe how you tested it.
