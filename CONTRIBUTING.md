# Contributing

Thanks for helping with the mods. Most work happens straight in the Windhawk editor.

## Ways to help

- Report mods that break after Windows or Windhawk updates
- Send compile fixes and small behavior tweaks
- Check that mod settings still cover the documented presets

## Getting set up

Mods are .wh.cpp files compiled inside Windhawk. To work on one, open the Windhawk editor, choose Create a new mod, paste the .wh.cpp content and compile.

## Checks before a pull request

- Compile the mod in the Windhawk editor before submitting
- Keep the settings snapshot complete: every documented option should still exist

## Where to submit

Open issues and pull requests in this repository.
