# Translucent Windows Plus

Blur, acrylic and mica for app windows, with per-app rules and custom themes. It is a fork of Translucent Windows that adds this repo's changes on top of the original.

## Features

- **Four background styles.** Blur, Acrylic, Mica and MicaAlt, picked per app.
- **Flyout effects.** Menus, dropdowns and tooltips can get the same look.
- **Custom theme rendering.** Keeps text readable on translucent windows and tints common controls.
- **Per-app rules.** Turn effects on or off for any program, each with its own style.

## Notes

- Modern (UWP and WinUI), Electron, Qt and Chromium apps are mostly out of reach. The FAQ in the mod's settings page explains why.
- Some dialogs can stay solid black, for example Explorer's Delete Folder confirmation.

## Install

1. Install [Windhawk](https://windhawk.net/).
2. Choose **Create a new mod**, paste [translucent-windows-plus.wh.cpp](translucent-windows-plus.wh.cpp) and click **Compile**.
