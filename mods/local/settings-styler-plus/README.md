# Settings Styler Plus

[☕ Support on Ko-fi](https://ko-fi.com/DavidHiFi)

Themes for the Windows 11 Settings app, based on Windows 11 Settings Styler.
This version adds two things: the normal Windows title bar, and a blur that
stays put when you click on another window.

![Settings Styler Plus preview](https://raw.githubusercontent.com/DavidHiFi/davids-windhawk-mods/main/media/previews/settings-styler-plus.png)

## Features
- **Every theme and setting from the original.** Pick a theme or write your
  own styles, same as before.
- **Normal title bar.** Turn on **Normal title bar** to get the standard
  Windows title bar with its usual minimize, maximize and close buttons
  instead of the one Settings draws itself. Off by default.
- **Blur stays when you click away.** Normally Settings turns flat gray as soon
  as it loses focus. With **Keep the blur when Settings isn't focused** on
  (the default), the blur stays.

## How to install
1. Turn off Windows 11 Settings Styler if you have it, so the two don't fight.
2. In Windhawk, click **Create a new mod**.
3. Replace the code with
   [settings-styler-plus.wh.cpp](settings-styler-plus.wh.cpp).
4. Click **Compile Mod**, then **Exit Editing Mode**.
5. Close and reopen Settings.
