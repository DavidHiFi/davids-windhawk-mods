# Everything & Power Tools in the Start Menu Plus

Search files, apps and settings from the Start menu with voidtools Everything. The menu opens as a compact search box with power controls and expands when you type.

![Everything Start menu Plus preview](https://raw.githubusercontent.com/DavidHiFi/davids-windhawk-mods/main/media/previews/start-everything-plus.png)

![Compact Start menu with power controls](https://raw.githubusercontent.com/DavidHiFi/davids-windhawk-mods/main/media/previews/start-everything-plus-idle.png)

## Features

- **Compact idle menu.** Keep the search box and native power controls visible without an empty results panel.
- **Results when you need them.** Typing expands the menu. Clearing the query or pressing Escape returns to the compact view.
- **Everything file search.** Search the existing Everything index alongside apps and Windows settings.
- **Power tools.** Use the original calculator, unit conversions, network tools and web shortcuts.
- **Keyboard navigation.** Move between results with the keyboard, open with Enter, or use Ctrl+Enter to run as administrator.
- **Start Menu Styler support.** Keep the menu's background, rounded border and theme colors.

## How to use

Open Start and type a query. Everything must be running to return file results. Apps and settings remain available when no files match.

Disable the original Everything & Power Tools in the Start Menu mod before enabling this one.

If your Start Menu Styler theme limits the frame height, allow at least 500 pixels. This mod handles the compact idle height. If you use Start Menu Size, leave its fixed menu height at 0 so it does not override the compact view.

The preview uses [OnlySearch Mocha's Everything variant](https://github.com/DavidHiFi/davids-windhawk-mods/blob/main/themes/start-menu-onlysearch-mocha/onlysearch-mocha-everything-plus.yaml).

## Install

1. Install [Windhawk](https://windhawk.net/) and [Everything](https://www.voidtools.com/).
2. Choose **Create a new mod**, paste [start-everything-plus.wh.cpp](start-everything-plus.wh.cpp), and click **Compile**.
3. Disable the original mod and enable this one.
