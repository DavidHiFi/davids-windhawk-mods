# Taskbar Elastic WinUI Pill Plus

An animated pill that slides under the app you switch to on the taskbar. It can also sit under every open app you're not using, so you can see at a glance what's running.

![Taskbar Elastic WinUI Pill Plus preview](https://raw.githubusercontent.com/DavidHiFi/davids-windhawk-mods/main/media/previews/taskbar-elastic-pill-plus.png)

## Features

- **Sliding pill.** The pill glides to the app you switch to, with stretch, bounce and other styles.
- **Pick which apps get a pill.** The app you're using, the open apps you're not using, or every open app.
- **Your size and shape.** Set the width, height, corner roundness and distance from the bottom.
- **Your colors.** Use the system accent, your own color or gradient, or a color taken from each app's icon.
- **Hover and click effects.** The pill can grow, shrink or change color when you point at or click an app.
- **Start, Search and Task View too.** Optionally give those buttons the pill as well.

## Tips

- If you also use a mod that already highlights the app in front, such as Taskbar Blob, set **Show the pill on** to **Open apps you're not using** so the two never stack.

## Install

1. Install [Windhawk](https://windhawk.net/).
2. Choose **Create a new mod**, paste [taskbar-elastic-pill-plus.wh.cpp](taskbar-elastic-pill-plus.wh.cpp) and click **Compile**.
