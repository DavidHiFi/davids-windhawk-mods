# Explorer TreeItem Tweaker Plus

[☕ Support on Ko-fi](https://ko-fi.com/DavidHiFi)

Rounded, colored highlights for the folders in File Explorer's left pane, with
your own colors, sizes and font. This version keeps working when other mods
also restyle that pane, and restarts Explorer for you instead of asking.

![Explorer TreeItem Tweaker Plus preview](https://raw.githubusercontent.com/DavidHiFi/davids-windhawk-mods/main/media/previews/explorer-treeitem-tweaker-plus.png)

## Features
- **Your own highlight.** Pick the fill, border and text color for hovered,
  selected and unfocused items, plus how round the corners are.
- **Layout controls.** Change row height, icon size, the gap between icon and
  text, and the font.
- **Hide the pin button.** Remove the Quick Access pin from the left pane.
- **Plays well with other mods.** The highlight stays put even with
  Translucent Windows installed, after reboots and mod updates.
- **No restart popup.** The colors only fully show up after Explorer restarts.
  This version restarts Explorer once on its own. Turn off **Restart Explorer
  without asking** in the Global settings to get the original popup back.

## How to install
1. In Windhawk, click **Create a new mod**.
2. Replace the code with
   [explorer-treeitem-tweaker-plus.wh.cpp](explorer-treeitem-tweaker-plus.wh.cpp).
3. Click **Compile Mod**, then **Exit Editing Mode**.

The default colors are made for dark mode. On light mode, set the normal text
color to black (R 0, G 0, B 0).
