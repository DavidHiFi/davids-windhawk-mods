# Header gap, tags line and rename box (2026-11-10)

## What was wrong
- Column header sat about 32 px below the toolbar and hover landed a row low. The page-slide
  bridge in GPU Accelerated Explorer View Plus is created at the slide's start offset (32 =
  PageAnimation.distance). DetachComposition cleared the transform but never zeroed that
  offset, so a slide that ended early left the list parked low. Visual only, so hit targets
  stayed put: one row off.
- Tags separator was inset 10 dip left and 8 dip right.
- Rename field was a plain EDIT with WS_BORDER: square box, light default colours.

## Changes
- GPU mod 1.3.5 -> 1.3.7 (1.3.6 was the first pass of the same fix):
  - DetachComposition sets bridge offset X and Y to 0 before removing it.
  - Rename EDIT: no WS_BORDER; 2 px non-client edge drawn as a rounded rect (grey resting,
    Mocha blue focused), round region, 4 px text margins, Mocha surface0 fill and text via
    WM_CTLCOLOREDIT in the frame subclass.
- explorer-tags 0.7.1 -> 0.7.2: separator runs 0..width.

## Checked
- Both installs by registry hot-swap, shell pid unchanged over 20 s, new DLL in all Explorers.
- Fresh window, 4 fast in-and-out navigations: header flush every time. Rename opened via
  Shell SelectItem(edit), captured at 4x, closed with Escape. Tags line edge to edge.

## 2026-11-11 midday: real cause and 1.4.8

- The stuck gap equals the page-slide distance setting (32 px; once 18 px mid-slide). Child window rects are the same in good and stuck states, so the list visual itself is translated.
- Cause: the GPU view slide effect (translate + opacity) stayed attached to the visual. Settle, the end pin and a new-visual reset only zeroed it when the remembered visual matched, and otherwise just dropped the pointers, leaving the effect parked.
- 1.4.8: new PageAnimDetachEffect zeroes the translate, sets opacity 1 and calls SetEffect(nullptr) on the old visual. Used by Settle, the end pin, EnsureEffect and DropTarget. Re-arm now settles before making a new effect. Trace from 1.4.7 removed.
- Tags line: the live mod is the tags-plus fork; 0.8.2 paints the line edge to edge (x 8 to 249). Old explorer-tags stays off.
- Rollback: install backup\gpu-1.4.6.wh.cpp (or 1.4.7 dll) with install.ps1.
