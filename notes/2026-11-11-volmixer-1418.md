# 2026-11-11 Mixer 1.4.18: master volume number back beside the tray speaker

Owner asked: where is the master volume number next to the volume mixer icon.

## Root causes (three)
1. The number window never drew. `PaintTrayNumberOverlay` selected its bitmap into a second DC
   while it was still selected in the first; a bitmap lives in one DC at a time, so
   UpdateLayeredWindow got the empty default bitmap and pushed a fully transparent window.
   The "number" seen in the 1.4.17 checks was Fan Control's tray icon (it shows fan %).
2. `TIMER_TRAY_SYNC` and `TIMER_NAME_TOOLTIP` both had id 4. WM_TIMER handled the tooltip first,
   so the number never moved after its first placement (stuck at -32,-9 from an empty rect).
3. By design the number sat over the icon slot to the speaker's left (Fan Control).

## Changes
- Mixer 1.4.17 -> 1.4.18: present from the DC that holds the bitmap; TIMER_TRAY_SYNC = 7;
  an empty icon rect counts as no slot; the tray icon gets the tip "Seamless Volume Mixer"
  (NIF_TIP, no NIF_SHOWTIP, so version 4 shows no shell bubble).
- Styler rule 64: `SystemTray.NotifyIconView#NotifyItemIcon[AutomationProperties.Name=Seamless Volume Mixer]`
  Margin=30,0,0,0, a gap left of the speaker where the number sits.

## Verify (10:04 pm)
- Graphics-capture frame shows "100" in the gap beside the speaker; Fan Control unchanged.
- UIA: speaker button named "Seamless Volume Mixer" at x 2263, Fan Control at 2205, gap between.
- The number window followed a tray shift (2231 -> 2226), so the sync timer runs.
- Explorer PIDs unchanged. Not checked live: a volume change updating the number, and no
  hover bubble on the speaker (owner at the PC, cursor not moved).
