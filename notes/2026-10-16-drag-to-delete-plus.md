# Drag to Delete Plus — fork created and installed (2026-10-16)

Created the requested fork of the drag-to-delete Windhawk mod as
**Drag to Delete Plus** (`local@drag-to-delete-plus`), fully autonomous per the
owner's instruction. Catppuccin Mocha with a blue accent applied as the defaults.

## What was built

- Source: `davids-windhawk-mods\mods\local\drag-to-delete-plus\drag-to-delete-plus.wh.cpp`
  (fork of [Drag to Delete](https://windhawk.net/mods/drag-to-delete) by iMAboud,
  `@author DavidHiFi, iMAboud`, version 1.0.0, `Include=explorer.exe`).
- Readme: `davids-windhawk-mods\mods\local\drag-to-delete-plus\README.md`
  (style-guide layout, feature bullets, credits; a stale README left by an

- Preview: `davids-windhawk-mods\media\previews\drag-to-delete-plus.png`
  (1200x675, generated by `drag-to-delete-plus-build\make-preview.ps1`, run

## Features added over the original

- Background material: gradient glass, solid, acrylic blur (screen capture +
  box blur behind the target), mica tint, or none.
- Colors for background (gradient top/bottom or solid), border, icon, shadow
  and hover tint - all `0xAARRGGBB` strings like translucent-flyouts uses.
- Shape: circle, rounded square (with corner radius) or square.
- Border thickness, shadow spread, overall size (50-200%), top/bottom position.
- Accept copy-only drags (archives, browser downloads), red hover cue with a
  flash on a successful drop.

## Defaults (Catppuccin Mocha, blue accent)

`backgroundTop 0xE6313244` (Surface0), `backgroundBottom 0xBE1E1E2E` (Base),
`backgroundColor 0xE61E1E2E`, `borderColor 0xFF89B4FA` (Blue), `iconColor
0xFFCDD6F4` (Text), `shadowColor 0x3C11111B` (Crust), `hoverTintColor
0x64F38BA8` (Mocha red - the destructive cue). The defaults live in the mod's
settings block, so the Windhawk UI shows them with no registry writes.
