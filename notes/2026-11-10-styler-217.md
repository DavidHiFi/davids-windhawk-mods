# Windhawk Enhanced Styler 2.1.7: button gap, dialog frames, frosted dialogs

Date: 2026-11-10. Mod `local@windhawk-enhanced-styler`, 2.1.6 to 2.1.7. The 2.1.6 build was
never installed (its watcher was stopped); 2.1.7 carries all of 2.1.6.

## What changed

- Advanced tab, the row under the settings JSON box: Load and its three-dot menu button now have
  the same 8px gap as the dots button to Save, all three on one centre line.
- Dialogs (Installing, Compiling, Update mods, confirms): grey 2px frame at rest, blue to mauve
  frame on hover, like every other surface.
- Drop-down lists and menus (for example the Debug logging list): same gradient hover frame.
- Tooltip echo removed: the styler's own tooltip no longer pops a copy of an option's text
  ("None") over drop-down options or selects.
- Dialog fill: Mocha mantle (24,24,37) at 86%. The update list box is #232435, one step
  lighter than mantle and darker than the last try (owner: #11111b too dark, #313244 too light).
  Progress rail stays crust.
- Frosted glass behind dialogs: the whole page blurs (12px) while a dialog is open, under a light
  crust tint. Page text behind the dialog is no longer readable.

## Why the page blurs instead of a backdrop blur

`backdrop-filter` on the dialog or its dim layer did nothing to page text, even on a small test
layer (`work\2026-11-10-styler-buttons\z12.png`, `z13.png`). Same finding as
`2026-11-02-styler-popout-solid.md`: the window is see-through down to DWM, so a CSS backdrop
blur cannot hide page text. A plain `filter: blur()` on the app root does work, so the rule is
`body:has(open dialog) > #root { filter: blur(12px) }`. The dialog sits outside `#root`, so it
stays sharp. The rule is keyed on the dialog wrapper not being `display: none`, which antd sets
once a dialog has closed, so the blur goes away with the dialog.
