# Halo Launcher 0.6.6: own keys, typed shortcuts, Flow store modules (2026-11-22)

Owner asked (via the laptop thread): why the Ctrl+Alt+F10 "tweak settings" key exists next to
Ctrl+I; audit settings for redundancy; make shortcut keys fully editable like Flow (Win+R types
"> ", Ctrl+Alt+F10 types "Tweak Halo Launcher's settings"); list every Flow plugin store module,
off by default.

## Answers
- Ctrl+Alt+F10 is not redundant: it works from anywhere, even with Halo closed. Ctrl+I only
  works inside the open Halo window. It stays, now editable.
- Redundant and removed: the "Second open key" (`openKey`) and "Use the open key and shortcut
  keys" (`useFlowKeys`) settings. Open keys are now one list, each with its own switch.
  The registry `openKey` was empty, so nothing needed moving.
- Possible quirk left alone: Next page = PageUp, Previous page = PageDown are Flow's own
  defaults.

## What changed
- Engine (`work\2026-11-22-halo-keys\engine\HaloEngine.cs`, built on the other thread's
  1590430FECC1 so it also carries its wheel fix):
  - `HaloKeys.json` beside Flow's Settings.json holds every global key with text and on/off.
    First run builds it from Flow's Hotkey + CustomPluginHotkeys. Flow's two fields are kept
    in step with the entries that are on.
  - New ops: `keys`, `shorts`, `storeget`. New lines sent: `hk key text on`, `sc key value`,
    `store id name desc author version language website`.
  - `storeget` downloads each plugin zip, installs it with Flow's PluginManager, sets up
    Python or Node first when missing, then restarts the engine.
- Mod (`work\2026-11-22-halo-keys\local@halo-launcher.wh.cpp`, now 0.6.7 on top of the 0.6.6 panel fix):
  - General: open keys list ("Open key N" + "Use this key") and "Add an open key".
  - Keys: one group per shortcut key (Key, Types, Turned on), then "New shortcut key".
  - Search: typed shortcuts ("You type", "It becomes"), plus a new pair, with
    {clipboard} and {active_explorer_path} explained.
  - Modules: store modules as switch-only cards under "More from Flow's plugin store".
  - Save refuses ("Keep one open key on") when no open key would be left on.
  - Fields carry a `loaded` flag, so an empty field the owner typed into is not reset by a
    reload.
  - Note: Set_MakeFields says it is generated by gen.py from spec.py in
    work\2026-11-11-halo-launcher; the openKey/useFlowKeys rows were removed by hand here.
