## 0.7.1 fix and live proof (2026-11-23, 2:06 am to 2:11 am)

- Bug found in the 0.7.0 proof: History never showed on its first open after the helper
  started. Windhawk starts the tool process hidden, so the first ShowWindow(SW_SHOWNORMAL)
  on an overlapped window takes that hidden flag. Open() also returned early for an
  existing but hidden window. Fix in src\tools.cpp hist::Open: show again when not
  visible, and re-show an existing hidden window. The shared settings window
  (settings-block ShowWindow SW_SHOW) may have the same trap; posted on coop, left for
  settings-engine.py.
