# Windhawk Styler 2.0.45 polish (2026-10-13)

Update: the tab overflow trigger is fixed in 2.0.46. See `notes\2026-10-13-styler-2046-overflow-icon.md`.

Five owner-reported issues, fixed and verified live through the UI's CDP port (9333).

| Issue | Cause (measured) | Fix |
| --- | --- | --- |
| Number spinner arrows poke out of rounded inputs | antd v4 `.ant-input-number-handler-wrap` is a square 22x30 box flush to the right edge | Inset pill: 3px from top, right and bottom, 20px wide, radius `cornerRadius - 3`, one divider |
| Save bar touches the page card edges | `SaveSettingsCard` uses `margin: -12px -24px`, the full card padding | `margin-inline: -12px`, leaving a 12px gap each side |
| Open-in-browser and share buttons touch | `ModPageButtonsWrapper` has no gap | `gap: 6px` |
| Icons off center (back arrow, page buttons, nav, toolbar) | Fira Code line height drops inline SVGs 1.3 to 1.6px | `.ant-btn:has(>svg)` and icon-only buttons use inline-flex centering; widths unchanged |
| Modified-setting bar stays stock blue | Interface variable `--whui-setting-non-default: #177ddc` | Set it, `--whui-link(-hover)`, `--whui-selected-bg`, `--whui-setting-moved-bg` from the accent |
| No system menu on title bar right-click | Window has `WS_SYSMENU` and a 7-item menu, but the drawn caption never opens it | `MainWindowProc` opens it on caption right-click, icon click and Alt+Space, with normal enable states and dark menus |
