# Windhawk Enhanced Styler 2.1.5: tag, mode switch, tooltips, expanded view

Date: 2026-11-10. Mod `local@windhawk-enhanced-styler`, installed 2.1.3 to 2.1.5 (2.1.4 was built,
never installed; its header Create button, ribbon and save-dock rules ride along).

## What changed

- Mod id tag beside the title: dark #181825 chip, 2px #45475a edge, blue to mauve edge on hover.
- Visual / Textual switch: one #1e1e2e surface for both halves, full-height 2px divider, selected
  half in bold blue text, hover fills the whole half with darker #11111b. No sliding thumb.
- Native `title` tooltips (Expand (F11), Compact view, Ctrl+S, badges) are replaced by `#wh-tip`,
  same look as the antd tooltips.
- Save dock ends 10px before the panel scrollbar (was overlapping it by 4px).
- Expanded (F11) settings: the page behind is hidden (visibility), content centred to 1480px,
  dock clear of the window scrollbar. Expand is in-page, not window fullscreen.

## Registry

- `HKLM\SOFTWARE\Windhawk\Engine\Mods\local@windhawk-enhanced-styler` `LibraryFileName`
- Old: `local@windhawk-enhanced-styler_2.1.3_scroll.dll`
- New: `local@windhawk-enhanced-styler_2.1.5_polish.dll`

## Install / rollback

`scripts\2026-11-10-styler-215-install.ps1 -Action WaitInstall` (elevated) installs when the
Windhawk window closes. Rollback with the window closed: `-Action Rollback` (imports
`backups\2026-11-10-styler-215\mod-key.reg`, restores `live.wh.cpp`).
