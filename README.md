## Installation

1. Install [Windhawk](https://windhawk.net) on Windows.
2. Open the Windhawk app and go to the Mods section.
3. Search for "Taskbar Styler" and install it.
4. Open the Taskbar Styler mod settings and pick your colors.
5. Restart the app or reload the mod.

## Features

### Taskbar border

- Keep the blurred taskbar backdrop inside the border instead of spilling out.
- Set a custom border color with a gradient from your accent to a secondary color.

### Taskbar bars

- Style the taskbar icons, running indicators and the empty area.

## Notes

> [!NOTE]
> This mod is in beta. Some Windows builds may not render the taskbar style correctly.
