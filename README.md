# Windhawk Configuration

Workspace for Windhawk: mod settings, shell themes, local mod development, and
engine work. Split out of `H:\System Configuration` on 2026-09-28 so Windhawk has
its own home.

## Layout

| Path | What |
| --- | --- |
| `Windhawk\` | Mod sources, builds, and historical backups (moved from System Configuration; old paths still resolve via junction) |
| `davids-windhawk-mods\` | Public fork repo: https://github.com/DavidHiFi/davids-windhawk-mods |
| `mods\` | New local mod work |
| `docs\` | Reference: engine layout, settings formats, traps |
| `scripts\` | Reusable scripts (`-Audit` default where practical) |
| `notes\` | Change notes, one per topic, ISO dates |
| `reports\` | Diagnostics, logs, screenshots |
| `backups\` | Registry exports, receipts, rollback material |
